# 【記入サンプル】タスクの締切

> ここから下は書き方のサンプルです。実際に書くときは上のテンプレに記入し、ここは削除してください。

## 概要

タスクに締切日を付けられる。締切を過ぎたタスクは一覧で目立たせる。

## 動作

1. タスク追加の画面で、締切日を選ぶ（空でもよい）
2. 追加すると、スプレッドシートの tasks シートに 1 行保存される
3. 一覧では、締切を過ぎたタスクが赤で表示される

## 受け入れ基準（AC）

| AC | 条件 | 確かめ方 |
|---|---|---|
| AC-1 | 締切は日付で入力できる | 確認用 URL |
| AC-2 | 締切を過ぎたタスクは期限切れと判定される（当日はまだ期限切れではない） | 自動テスト |
| AC-3 | 期限切れのタスクは赤で表示される | 確認用 URL |
| AC-4 | 締切なしのタスクも今までどおり登録でき、期限切れにならない | 自動テスト |

## データモデル

```
シート: tasks
- A列 id: 文字列
- B列 title: 文字列
- C列 due: 文字列（yyyy-MM-dd。締切なしは空）
- D列 done: 真偽値
```

## この機能で扱う大事なデータ

- [x] どれも扱わない（タスク名と日付のみ）

## 非機能要件

- **公開範囲**：自分だけ × 実行ユーザー 作った人

## 未確定事項
